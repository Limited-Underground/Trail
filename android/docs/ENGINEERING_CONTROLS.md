## Lessons retained at the responsible boundary

The accepted diagnostic history established subscription-aware Send readiness,
native-lane idle requirements, stale GATT database handling, current-session log
watermarks and measured UI-capture scheduling. These belong to the qualified
private source/runner evidence, not a claim that every correction is in public main.
The source/build and interface maps make that boundary explicit.

The reconstruction's initial unsigned guard rejected AGP's metadata task by name.
Pinned implementation inspection proved it only serializes version booleans;
the corrected isolated guard admits only that task/type while requiring a null
signing configuration and refusing signing tasks. Reuse the verified recipe;
do not redesign the transport, weaken ownership or make debugger availability
a normal UI/BLE readiness prerequisite.
