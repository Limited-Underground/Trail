# Funding application checklist

Status date: 2026-08-10

## Opportunity qualification

- [ ] Official program page and current application window verified.
- [ ] Applicant geography, entity type, age, revenue, and tax-status rules met.
- [ ] Open-source hardware/software work is eligible.
- [ ] Requested hardware, labor, travel, hosting, and contingency are eligible.
- [ ] Match, reimbursement, procurement, insurance, ownership, and audit rules understood.
- [ ] Intellectual-property, publicity, exclusivity, data-rights, and licensing terms acceptable.
- [ ] Reporting dates and measurable deliverables are achievable.
- [ ] Opportunity recorded in `OPPORTUNITY_REGISTER.md` with a dated status.

## Applicant readiness

- [ ] Private legal/financial readiness hold cleared for this exact cash or property request.
- [ ] Legal applicant/payee confirmed.
- [ ] Authorized signer confirmed.
- [ ] Applicant address, contact, registration, and tax fields confirmed.
- [ ] Dedicated bookkeeping category or project ledger prepared.
- [ ] Secure payment channel identified.
- [ ] Conflict-of-interest and related-party disclosures completed.
- [ ] Donated, discounted, or loaned property valuation, disclosure, ownership, shipment, and return obligations cleared.
- [ ] Insurance, participant consent, and site permissions checked if required.

## Narrative readiness

- [ ] Public name field intentionally selected or left as a neutral working label.
- [ ] Current phase is described as architecture/host/bench proof, not production.
- [ ] 300/300 soak and other measurements link to the matching public evidence.
- [ ] Unproved firmware, security, GNSS, field, regulatory, and hardware claims remain explicit.
- [ ] Base device independence from phone/server/repeater/internet is preserved.
- [ ] Safety limitations and privacy approach are included.
- [ ] Deliverables match the requested budget and period.
- [ ] No rescue, range, compatibility, certification, endorsement, or delivery guarantee is implied.

## Budget readiness

- [ ] Exact SKU, quantity, unit price, shipping, tax, and quote date recorded.
- [ ] Donated, loaned, discounted, owner-funded, and grant-funded value separated.
- [ ] Labor is explicit rather than hidden in equipment.
- [ ] Contingency follows program rules.
- [ ] Restricted and ineligible costs removed.
- [ ] Total matches every application field and attachment.
- [ ] Milestone payment/reimbursement cash-flow risk reviewed.

## Attachment readiness

- [ ] Project fact sheet tailored.
- [ ] Hardware support request tailored when applicable.
- [ ] Budget and milestone table finalized.
- [ ] Repository, license, contribution, and security links work.
- [ ] Relevant pilot plan and public evidence links work.
- [ ] Team biographies and references are factual and approved.
- [ ] Required registration, tax, banking, or identity documents are uploaded only through the official secure channel.
- [ ] Private application copy saved outside the public repository when it contains protected information.

## Submission and award control

- [ ] Final draft reviewed by the project owner.
- [ ] Terms, certifications, and representations reviewed before signature.
- [ ] Submission explicitly approved; no automated submission.
- [ ] Confirmation number, final copy, and deadline recorded.
- [ ] Award terms reviewed before acceptance.
- [ ] No purchase or public sponsor announcement occurs before acceptance authority.
- [ ] Reporting calendar and evidence owners assigned after acceptance.
