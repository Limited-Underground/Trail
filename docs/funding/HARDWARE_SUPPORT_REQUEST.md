## Request letter

Hello `[CONTACT OR ORGANIZATION]`,

I maintain OpenTrail, an Apache-2.0 open-source project exploring self-contained
ESP32-class LoRa communication, location-awareness, and safety-aid devices for
groups operating without reliable cellular service. The project is intended for
modular real-world uses including vehicle groups, racing support, camping,
off-road travel, rural property, severe weather, and volunteer field work.

The repository contains public architecture, deterministic host-tested
components, continuous integration, privacy-safe evidence tooling, and bounded
physical testing with two Heltec client nodes and a Seeed SenseCAP Solar
repeater. The current evidence includes a 300/300 five-hour close-bench message
soak. We do not yet claim production firmware, field readiness, or validated
compatibility for the hardware requested below.

We are seeking donated, discounted, or time-bounded loan hardware to build four
identical self-contained test units plus two spares and execute the first
documented four-person field pilot. We would value:

- six identical `[EXACT BOARD/SKU/REVISION]` units;
- compatible GNSS hardware and antennas, if not integrated;
- documented LoRa antennas/connectors appropriate for `[REGION/FREQUENCY]`;
- batteries, charging/power modules, and power documentation;
- display/input hardware required for phone-free operation;
- enclosure or mounting samples suitable for field prototyping;
- recovery/debug accessories and USB cables; and
- one technical contact for public documentation or pinout questions.

If support is provided, we will:

- identify the support and its estimated value in a public funding ledger;
- publish reproducible build, configuration, and test procedures;
- label the hardware only as candidate, experimented, or validated according to

- publish material failures and limitations as well as successful results;
- protect participant privacy and omit secrets or device-specific identifiers;
- follow applicable radio rules and vendor license/attribution requirements;
- avoid implying vendor certification, endorsement, or guaranteed safety; and
- return loaned equipment according to a written return agreement.

Support does not purchase editorial control, a positive compatibility result,
exclusive access, hidden test failures, or a production recommendation. Public
statements will distinguish donated equipment from independently measured
evidence.
