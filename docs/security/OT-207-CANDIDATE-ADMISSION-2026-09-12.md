## Primitive evidence

The bounded candidate primitive/vector gate is reconciled. Existing target evidence
contains SHA256/HKDF known answers, signing/encryption round trips and corruption
refusals. Independent expected Noise XK messages, transcript and split keys exercise
the actual target adapter's X25519, SHA256/KDF and ChaChaPoly composition.

A genuine missing direct Ed25519 expected-signature check was added: two published
fixtures already retained in pinned upstream `libsodium/test/default/sign.c`.
Their public keys and signatures are compared byte-for-byte, with changed-message,
signature and public-key refusals. All10 groups passed in the same scalar build
used for OT-206. Expected bytes were independently checked against the pinned
upstream file, not generated by the implementation under test. This is bounded
candidate evidence, not exhaustive conformance or production acceptance.

## Source, build and license evidence

Verified all731 upstream files,44 firmware source pins and seven matching retained
build artifact pairs. Each retained build's987 compiled-source pins,294 repository
dependencies and2325 external dependencies match. The exact managed source lock,
ISC license files and SPDX inventory also match their accepted admission digests.
The current target disables the component manager and binds vendored source and
compiled dependency closure; it does not have a generated target dependency lock.

existing SPDX inventories libsodium but represents ESP-IDF as one `NOASSERTION`

source hashes alone do not supply license attribution. No legal-clearance claim
