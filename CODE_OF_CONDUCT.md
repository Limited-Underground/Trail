# Community conduct

Trail welcomes people with different backgrounds, skill levels and interests.
This applies to repository issues, discussions, pull requests and other
maintainer-operated project spaces.

- Be respectful. Critique ideas and behavior without personal attacks.
- Give clear, constructive feedback and assume questions can be asked in good faith.
- Respect privacy. Do not publish another person's personal information or
  sensitive device, security or location data.
- Do not harass, threaten, discriminate, impersonate others or post spam.
- Keep claims honest: identify prototypes, simulations and test limitations.

Maintainers may edit or remove disruptive content, close or lock conversations,
and restrict participation. Responses should be proportionate to the behavior,
with repeated or serious misconduct potentially resulting in a ban.

Report conduct concerns privately to the repository maintainer through an
available private channel, or use GitHub's reporting tools. Do not publish
sensitive details in a public accusation. Security vulnerabilities follow
[SECURITY.md](SECURITY.md).
