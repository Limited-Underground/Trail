# Contributing to OpenTrail

OpenTrail is in an early architecture and proof-of-concept phase. The project is intended to become free/open source, but its license and contribution policy have not yet been selected.

Until those governance decisions are recorded:

- do not submit or accept external source-code contributions
- use issues and design discussions only for non-confidential planning
- do not post device keys, channel secrets, credentials, precise private locations, or personally identifying radio captures
- distinguish proposed behavior from tested evidence
- include hardware, firmware, radio configuration, setup, and observed results with hardware claims

Repository work must follow [AGENTS.md](AGENTS.md), the architecture boundaries in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), and the acceptance criteria in [tasks/BACKLOG.md](tasks/BACKLOG.md).

This file will be expanded when the license, contributor terms, code of conduct, review process, and release policy are selected.
