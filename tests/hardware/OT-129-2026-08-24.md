# OT-129 Monocypher start-ready protocol correction

**HOST-ONLY CORRECTION ACCEPTED — no device access, flash, benchmark, radio, or
phone operation occurred.**

OT-129 adds an isolated successor firmware target and dependency-injected capture

## Corrected contract

- Host endpoint lifecycle accepts either observed disappearance/return or three
  consecutive stable-present polls after one reset.
- Host retries exact `OTCBXCTL1 START\n` every 250 ms until exact READY.
- Device accepts exact START across arbitrary USB read fragmentation, accepts
  repeated START commands idempotently, drains `OTCBXCTL1 READY\n`, and cannot
  emit the first result frame before that drain succeeds.
- Host preserves partial bytes across empty reads, bounds partial lines and
  printable startup chatter, and sends only complete result lines to the frozen
  strict 1,014-frame parser.
- Benchmark time starts at READY. The transport never resets or reopens after
  START transmission begins.
- Failure codes and counters are closed and privacy-safe. Raw exceptions are
  discarded before sanitized errors are raised, leaving no exception context.
