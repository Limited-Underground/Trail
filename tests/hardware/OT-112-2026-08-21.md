# OT-112 — Heltec V4 direct-radio diagnostic build

Date: 2026-08-21

## Result

A separate `heltec_v4_radio_diag` ESP-IDF target now builds one identical
firmware image for both Heltec WiFi LoRa 32 V4.2 bench devices. The accepted
build uses ESP-IDF 6.0.2 and an exact RadioLib 7.7.1 dependency lock.

The diagnostic boots into receive mode and never transmits automatically.
Transmission requires a volatile one-use `arm` command valid for 30 seconds,
and the permit is consumed before the only transmit call. Structured `OTD1`
frames bind a nonzero session, sender role, consistent direction, sequence,
and deterministic 1–163-byte fill. Logs omit raw payload bytes.

The fixed build profile is 915.000 MHz, 125 kHz bandwidth, SF7, CR 4/5,
sync word `0x12`, eight preamble symbols, explicit header, CRC, LDRO forced
off, 1.8 V TCXO, and a 2 dBm SX1262 command setpoint. The sync word is a
packet discriminator, not encryption; emitted power/EIRP is not measured.

## Boundary

No device was accessed, erased, flashed, reset, or commanded to transmit.
This is source/build evidence only. Physical initialization, bidirectional
delivery, loss/duplicate/corruption behavior, RSSI/SNR, restart behavior,
actual RF output, regulatory acceptance, compatibility, and support remain
unproven.
