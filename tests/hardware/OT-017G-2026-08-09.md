# OT-017G Physical Retryable Rate-Limit Rejection

Date: 2026-08-09

Status: passed for two role-reversed close-bench cycles using production host
components from OpenTrail and OpenGauge. This is bounded host-mediated evidence,
not persistent on-device state, physical authentication, or field behavior.

## Purpose

Complement the OT-017F terminal rejection with a retryable rejection. The
OpenTrail bridge filled the real ingress general-rate allowance with four valid
unique events, then processed the physically received normative alert as the
fifth event in the same window. The real responder emitted rejected/rate-limited.

OpenGauge reconstructed the exact sent event as in-flight and processed the
returned physical ACK through authorization, session, replay/correlation, and
negative-ACK policy. Success required no delivery acknowledgement or outbox
completion, `retry_released=true`, `terminal_failure=false`, exactly one queued
event, and zero in-flight entries.

## Results

| Measure | Cycle 1 | Cycle 2 |
| --- | ---: | ---: |
| Exact alert / correlated rejection | 1/1 / 1/1 | 1/1 / 1/1 |
| OpenGauge processed / completed | yes / no | yes / no |
| Delivery acknowledgements | 0 | 0 |
| Retry released / terminal failure | yes / no | yes / no |
| Final queued / in-flight | 1 / 0 | 1 / 0 |
| Alert / ACK latency | 484.4 / 493.8 ms | 493.0 / 499.2 ms |
| Host-observed round trip | 1000.8 ms | 1008.3 ms |
| Alert / ACK SNR | 11.75 / 12.00 dB | 12.00 / 11.50 dB |
| Alert / ACK duplicates | 0 / 0 | 0 / 0 |
| SenseCAP flood RX / TX | +2 / +2 | +2 / +2 |

Both Heltecs recorded one sent and one received frame per cycle with zero new
core/receive errors and empty radio queues. SenseCAP repeat remained on, its
errors did not increase, endpoint cleanup passed 4/4, and no lease journal
remained. No secret or private device identifier is recorded.

## Remaining gates

- Preserve the queued event and exact backoff/attempt state across a real
  process/device restart, then send and accept the retry.
- Exercise loss, corruption, duplicate, delay, reorder, replay, rebind, revoke,
  and power-loss behavior with durable target state.
- Bind protected keys and real transport identity to selected target adapters.
- Replace the host/MeshCore adapter with direct authenticated on-device
  transport and run field/range evidence.
