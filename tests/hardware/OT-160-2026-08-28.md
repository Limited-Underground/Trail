# OT-160 Noise XK hash-helper host correction

**HOST-ONLY CORRECTION — no device, phone, private endpoint, firmware build,
physical read, physical reset, flash, application write, radio operation,
journal, receipt, bundle, authority, or cryptographic measurement occurred.**

## Problem boundary

OT-159 preserved two exact physical Trail application readbacks and two
completed hard resets. Both subsequent official OT-157-bound preflight attempts
stopped before the exclusive journal, first benchmark write, radio path,
receipt, or authority-consumption boundary.

The inherited OT-153 adapter verifies an application by passing readback bytes
to `coordinator._sha256(readback)`. The substituted OT-157 coordinator exports a
same-named file helper accepting a `Path` and calling `path.read_bytes()`. Its
local symbol shadows the inherited `_sha256(bytes)` helper, so the accepted
composition rejects exact bytes deterministically. This is a host-composition
defect, not evidence of a device, USB, firmware, antenna, or radio defect.

## Accepted correction

The fresh OT-160 coordinator:

- verifies immutable source files through `_source_sha256(Path)`;
- defines no local `_sha256`, so module fallback exposes the frozen OT-153
  `_sha256(bytes)` helper;
- retains the immutable OT-153 restoration-safe state machine and exact OT-156
  reset-aware runner;
- uses fresh `ot160-*` journal and receipt filenames with schemas `OT160NXJ0`
  and `OT160NXCR0`.

The fresh OT-160 adapter pins that coordinator, the immutable OT-153 concrete
adapter, and the immutable OT-156 reconnectable runtime. It rebinds both the
frozen adapter and runtime adapter coordinator references to OT-160. Its
default authority boundary names the absent future OT-162 tool and record, so
ordinary loading remains fail-closed and cannot reuse OT-158.

The focused adapter suite invokes the actual inherited
`ReconnectableEsptoolSerialBackend.verify_application` through the actual

For exact fixture bytes, the test observes:

For both a corrupt first readback and a short first readback, the composed path

host test roles and mocked transport commands, not new physical node actions.
