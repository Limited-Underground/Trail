# OT-017H Physical Rate-Limit Retry to Accepted Completion

Date: 2026-08-09

Status: passed for two role-reversed four-leg close-bench sequences. This uses
real host components and physical radio bytes but reconstructs OpenGauge state
after both responses; it is not durable live on-device state or authentication.

## Sequence and acceptance

Each endpoint role performed:

1. exact normative `OGA0` physical delivery;
2. exact correlated rejected/rate-limited `OGK0` return;
3. OpenGauge retry release with zero acknowledgement/completion;
4. not-ready verification before the exact 25 ms backoff boundary and
   byte-identical retry preparation at 26 ms;
5. a second exact physical delivery of the same alert;
6. correlated accepted/none return with the next ACK sequence; and
7. final completion with one acknowledgement and zero queued/in-flight state.
