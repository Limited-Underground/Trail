## Accepted target

`monocypher_ot139_quiet` is a separate ESP-IDF target. Its component definition
compiles the frozen OT-129 `app_main.c` and `ot129_control_protocol.c` directly
from the accepted source directory; it does not copy or rewrite them. The only
successor-specific behavior is the target-local build configuration.

The resolved generated sdkconfig proves:

- primary console: none;
- secondary console: none;
- bootloader log level: none (`0`);
- default application log level: none (`0`);
- maximum application log level: none (`0`);
- direct USB Serial/JTAG driver: enabled;
- build graph: required main component and declared dependencies only; Bluetooth and Wi-Fi excluded;
- reproducible application build: enabled; and
- ROM logging policy: normal always-on behavior, with no eFuse/GPIO suppression.

The last item is deliberate. ESP32-S3 ROM output can occur before application
configuration takes effect. OT-139 isolates ESP-IDF bootloader/application
console output from the direct control protocol; it does not claim the physical
USB endpoint is silent from reset or that ROM output was observed or removed.
