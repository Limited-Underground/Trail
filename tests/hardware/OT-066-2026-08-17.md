# OT-066 Trusted Phone GATT Authority Composition

Date: 2026-08-17

## Accepted scope

OT-066 adds one target-neutral production composition between private bond
evidence, the existing device-secret binding resolver, the durable one-phone
authorization authority, and the existing GATT authorization seams.

The trusted binding owner pins one opaque private reference to one exact live
connection generation, produces only private device-minted claim values, and
caches a successful result exactly. The authorization adapter maps first claim,
owner reconnect, explicit replacement, and exact controller release to the
existing durable authority.

store, protected target persistence, provisioned keys, an independent physical
rollback floor, a physical claim/replacement gesture, phone pairing, GATT
exchange, application authorization, Ready, or device runtime. No partition,
sdkconfig, target runtime, Android app, firmware image, or physical device
changed.
