# OT-074 protected-storage source proof

Date: 2026-08-17

Status: done; source prerequisite satisfied only

## Scope

This record covers the accepted bounded read-only operation used to collect the
exact OT-070 protected-storage source prerequisite from `OT-DEV-001`. The
operation was limited to the 3,072-byte installed partition-table range and the
complete 1 MiB source region. It granted no write, erase, reset, key, eFuse,
partition-transition, recovery, or runtime-activation authority.

The operation used esptool 5.3.1 with direct ESP32-S3 ROM access and no RAM
stub. It read only the two admitted ranges.

## Result

The fixed sanitized result was:

`OTPSTE1/v0` / `SOURCE-PROOF-SATISFIED-ONLY`

The exact installed 3,072-byte partition table matched the accepted source
layout identity. The complete 1,048,576-byte source region was all `0xFF` and
matched the accepted blank-region identity.

No raw bytes, paths, transient port, device identifier, private operation or
evidence identity, or detailed transport output was retained. The temporary
executor and bytecode were deleted immediately after the operation, and
cleanup was verified.

## Startup/status observation

With PRG released, the owner pressed RST once. The recognizable Trail logo and
`BLE ADVERTISING` status returned. This is a bounded startup/status observation;
no heartbeat capture, Android scan, write, or recovery procedure was performed.

## Remaining boundary

This result satisfies only OT-070's source prerequisite. It does not authorize
the partition transition or prove protected NVS, protected key roles, an
independent rollback floor, private bond persistence, GATT authorization,
Ready, LoRa, or GNSS. Exact-unit recovery evidence and a separate physical-write
authorization remain required before any partition transition.
