# OT-069 Inactive Heltec Authorization NVS Context

Date: 2026-08-17

Base commit: `ad190eaece3dfc8c15b8c843e55dcc33c5cb52af`

## Accepted scope

OT-069 adds one target-local owner for an exact, already provisioned encrypted
NVS context. It can make the OT-068 backend available only after the exact
candidate partition, existing security configuration, secure initialization,
and namespace open all succeed. The owner is build-compiled but not included,
constructed, called, or injected by the running firmware.
