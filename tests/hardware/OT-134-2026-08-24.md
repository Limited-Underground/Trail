- Exists: yes
- Canonical length: 5,454 bytes
- `MAX_BYTES`: 131,072
- Canonical and expected SHA-256: `b7be03e305c6253e10f69f624132a736cce5aea3f559760cde4f948ae79abad6`
- Canonical encoding: no BOM, 40 LF line endings, final newline present

The file was neither empty nor oversized. Git history and blob comparison found no content, serialization order, timestamp, path, metadata, BOM, or final-newline change between OT-098 and current.
