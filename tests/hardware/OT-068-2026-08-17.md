## Accepted scope

OT-068 adds one target-local ESP-IDF NVS implementation of the OT-067 exact
protected-KV backend. The adapter receives an already-opened handle and is
compiled into the Heltec component, but no target runtime source includes,
constructs, opens, or injects it.
