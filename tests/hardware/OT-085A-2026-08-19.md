- shares the application's fixed GATT/public-value contract;

- emits only fixed per-gate PASS/DENY fields with no raw failure detail.

The hardened instrumentation APK also compiles and assembles. It was not rerun
against hardware, so cleanup validation adds no second physical claim.

## Boundary

This accepts one fixed, public, read-only transport record and the
phone-disconnect return to advertising. The firmware's independent 15-second
automatic termination path was not physically exercised.

`BLE CONNECTED` means only that one BLE transport link existed. This result
does not prove pairing, encryption, authenticated bonding, ownership, trusted
phone state, protected Protocol Info/Command/Stream access, provisioning,
persistence, Ready, messaging, LoRa, GNSS, complete recovery, power endurance,
field operation, regulatory acceptance, or supported hardware.
