## Preflight and execution observations

Before the irreversible consumption boundary, both anonymous nodes passed
exact installed-Trail application readback and hard reset, and the owner
confirmed that both displays returned to the Trail logo. The accepted
authority was then consumed exactly once.

Both anonymous nodes passed benchmark application readback and hard reset
before the bound runner was entered. The runner terminated fail closed as
`radio_run_failed` at the exact allowlisted stage `restart_ack_a`.
`radio_run_invoked` is `true` and `radio_result_validated` is `false`.

The stage proves only that the required restart acknowledgement for anonymous
role A did not complete. It does not expose or establish an endpoint, host,
USB, firmware, physical-radio, or other root cause. No exception, backend text,
raw serial, command response, payload, identifier, or private state is
published.

## Exact restoration

The unconditional restoration boundary ran for both benchmark-touched nodes.
Each anonymous node passed:

- exact Trail application write;
- exact Trail application readback; and
- hard reset after restoration.

`restoration_complete` is `true`, `recovery_required` is `false`, and no
recovery receipt exists. The owner confirmed that both displays returned to
the Trail logo after the abort.
